# Support

- Usage questions belong in
  `https://github.com/mauhpr/constraintloop/discussions`.
- Reproducible bugs belong in the repository bug issue form.
- Scoped feature proposals belong in the repository feature issue form.
- Security reports must follow `SECURITY.md` and must not be filed publicly.

Support is best effort and does not include provider fees, third-party agent
behavior, or custom contract design.
